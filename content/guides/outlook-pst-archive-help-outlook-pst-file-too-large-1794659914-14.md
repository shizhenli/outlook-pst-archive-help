You are working in classic Outlook with a local PST archive, and Outlook or Windows refuses to open or move the file because it has exceeded a size limit. Before you attempt any repair, confirm the actual limit and the file's true size, because moving or forcing open an oversized PST can corrupt it further.

## Confirm the File Size and the Limit

Close Outlook completely. In File Explorer, navigate to the PST, right-click it, choose Properties, and note the exact size in GB. Compare that number to the limit for your Outlook version and PST format: ANSI PSTs are capped at 2 GB, while Unicode PSTs default to 50 GB but can be configured lower. If the file size is at or above the cap, the refusal is expected and not a sign of corruption.

## Test Whether Outlook Can Still Read the File

Reopen Outlook and try to access the archive through File > Open & Export > Open Outlook Data File. If Outlook returns a size-limit error immediately, stop. Do not retry repeatedly. Instead, make a copy of the PST to a separate drive before any further action, so the original remains untouched.

## Verify the Outcome

After copying, check that the duplicate opens or mounts without the same error. If the copy behaves identically, the limit is confirmed and the file must be reduced or split before it can be moved. If the copy opens, the original may have a separate lock or path issue, not a size problem.

## Rollback and Recovery

Keep the untouched original until you have verified a working copy. If any step makes the PST unreadable, restore from that original rather than attempting in-place repairs. For a confirmed **outlook pst file too large** condition, professional guidance can prevent permanent loss.
