- title: Copy the PST before opening
  text: Work on a duplicate and keep the original read-only. Record its size, path, and Outlook profile.
- title: Check the export root
  text: Confirm whether the export started at the mailbox root or a selected folder. A missing root explains a missing subtree.
- title: Compare folders and counts
  text: List the source folder tree and compare it with the PST. Check message counts and a date range, not only the top-level folder.
- title: Open sample attachments
